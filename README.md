# Cüe-Ligans Management App (apa)

## Objective

Build a management application to track and manage Cüe-Ligans league data.

## Features

- **Player Stats**
  - Skill Level (SL)
  - Points Per Match (PPM)
  - Points Allowed (PA)
  - Win Percentage (Win %)

- **Weekly Scores**
  - 8-Ball scores
  - 9-Ball scores

- **Division Standings**
  - Track team rankings within divisions

- **Game Schedule**
  - Manage and display upcoming matches

- **Match History**
  - Record and review past matches

- **Team Dues and Payments**
  - Track team payments and outstanding dues
