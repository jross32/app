Script Guide
  • URL Discovery: crawls APA endpoints and updates capture targets.
  • API Sniffer: hits those endpoints to produce a fresh api_dump_v2.json in a new capture folder.
  • Run Update: runs both discovery + sniffer, snapshots the raw dump, copies to data/, and auto-merges into the main league data file with a backup first.
Tips:
  • Reload the page after a run to view output alerts.
  • Use "Restore from backup" if a merge goes wrong.
